In linux terminal

Installing prerequisites:
> sudo apt update
> sudo apt upgrade
> sudo apt install build-essential curl gcc make pkg-config libssl-dev


Installing Rust:
> curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
> source "$HOME/.cargo/env"


Installation check:
> rustc --version
> cargo --version
> rustup --version
